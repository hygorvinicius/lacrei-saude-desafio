LACREI SAÚDE — INÍCIO RÁPIDO (DESENVOLVIMENTO LOCAL)
=================================================

Pré-requisitos: Git, Docker Engine e Docker Compose.

1. Clone o repositório:
   git clone https://github.com/hygorvinicius/lacrei-saude-desafio.git
   cd lacrei-saude-desafio

2. Crie seu arquivo de configuração local:
   cp .env.example .env
   # Ajuste DJANGO_SECRET_KEY para um valor de desenvolvimento.
   # As credenciais locais do PostgreSQL estão no docker-compose.yml.

3. Suba o ambiente local:
   docker compose up -d --build
   docker compose ps

4. Verifique a API:
   curl -i http://127.0.0.1:8000/health/
   # Resposta esperada: {"status":"ok"}

5. Execute testes e verificações:
   docker compose exec web python manage.py test
   docker compose exec web python manage.py check

6. Para criar um usuário local de demonstração:
   docker compose exec web python manage.py createsuperuser

Documentação completa: README.md
Swagger: http://127.0.0.1:8000/api/docs/
Evidências de staging e produção: docs/GUIA_DA_REVISAO.md

OBSERVAÇÃO: este roteiro é local. Os servidores AWS foram publicados
via GitHub Actions, sem necessidade de criar novas instâncias para o teste.
Não compartilhe .env, .env.aws, chaves SSH, tokens, dumps ou dados reais.
